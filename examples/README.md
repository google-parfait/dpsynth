# DPSynth Examples

This directory contains self-contained, runnable scripts and notebooks that each
showcase a distinct capability of DPSynth across tabular, discrete, sequence,
and free-form text workflows. Companion helpers in `datasets/` download and
prepare public reference datasets so every example can be run without checking
data into Git.

For a summary table of all examples, the capabilities they demonstrate, and
end-to-end command-line walkthroughs, see the
[Examples guide on ReadTheDocs](https://dpsynth.readthedocs.io/en/latest/examples.html).
